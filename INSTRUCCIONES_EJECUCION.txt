==============================================
INSTRUCCIONES DE EJECUCIÓN DE PROCOME
==============================================

PROCOME es una aplicación Qt (PySide6). La forma recomendada de ejecutarla es el
script run.sh, que crea el entorno virtual, instala las dependencias y arranca:

   ./run.sh

Otras formas:

2. CON EL ENTORNO ACTIVADO:

   source .venv/bin/activate
   python3 PROCOME_Arranque_Qt.py

3. EJECUTABLE COMPILADO (ver EJECUTABLE.md):

   ./build.sh          # compila -> dist/PROCOME
   ./dist/PROCOME

4. DESDE EL MENÚ DE APLICACIONES (opcional):

   sudo cp PROCOME.desktop /usr/share/applications/

   Luego buscar "PROCOME" en el menú de aplicaciones.

NOTAS:

- La aplicación fuerza QT_QPA_PLATFORM=xcb (XWayland) para poder colocar la consola
  (40 % izquierda) y la ventana principal (60 % derecha). En Wayland nativo el
  compositor ignora la posición de las ventanas.
- El usuario debe pertenecer al grupo "dialout" (o "uucp" en Arch) para acceder al
  puerto serie.

- Historial de versiones: VERSION.md
